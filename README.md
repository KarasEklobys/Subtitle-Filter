# Subtitle Filter

**Оставляет в субтитрах только то, что важно.**

Программа для Windows, которая находит в `.srt`-файлах строки с нужными
словами и убирает всё остальное — так можно за секунды найти в видео
нужные моменты, вместо того чтобы вручную пролистывать десятки минут
субтитров. Особенно полезно, когда обрабатываешь субтитры пачками (10, 50,
100 видео за раз) и точно знаешь, что именно ищешь.

---

## Зачем это нужно

Допустим, у тебя есть сотня видео и автоматически сгенерированные к ним
субтитры (например, через Whisper). Тебе не нужно смотреть или читать всё —
нужны только моменты, где встречаются конкретные слова или фразы.

**Subtitle Filter** делает это за один клик:

- Ты один раз задаёшь список слов.
- Скармливаешь программе файлы или целую папку с `.srt`.
- На выходе — новые файлы субтитров, где остались только нужные строки,
  с теми же таймкодами. Открываешь такой файл вместо оригинала в любом
  плеере (например, PotPlayer) — и видишь только то, что искал.

---

## Возможности

| | |
|---|---|
| 🔍 **Поиск по списку слов** | Просто список — по одному слову или фразе на строку |
| 🔤 **Регистр не важен** | «Папа», «ПАПА» и «папа» — одно и то же |
| 🎯 **Целые слова / часть слова** | Переключается галочкой — «рот» не подхватит «ворота», если не нужно |
| 📁 **Пачками** | Можно выбрать сразу папку — обработает все `.srt` внутри (проверено на 100+ файлов) |
| 💾 **Список слов сохраняется** | Экспортируй в `.txt` и загружай заново — не набирай каждый раз |
| ⏱ **Таймкоды не трогаются** | Файл сразу открывается в плеере на нужном месте |
| 🖥 **Просто .exe** | Не требует установки Python или чего-либо ещё |

## Как скачать

1. Перейди во вкладку **[Releases](../../releases)** этого репозитория
   (справа на странице репозитория на GitHub, или по ссылке выше).
2. Открой самый свежий релиз и скачай файл **`SubtitleFilter.exe`**
   из раздела Assets.
3. Больше ничего не нужно — это одиночный исполняемый файл. Установка
   не требуется, Python на компьютере тоже не нужен.

> Windows может показать предупреждение SmartScreen («Windows защитила ваш
> компьютер»), потому что файл не подписан цифровой подписью издателя —
> это нормально для независимо собранных программ. Нажми
> **«Подробнее» → «Выполнить в любом случае»**.

## Как пользоваться

1. Запусти `SubtitleFilter.exe`.
2. В левой панели впиши слова, которые нужно найти (по одному на строку).
3. В правой панели нажми **«Выбрать файлы»** или **«Выбрать папку»** и
   укажи свои `.srt`.
4. Нажми **«Обработать»**.
5. Готовые файлы появятся в подпапке `filtered` рядом с исходными —
   их можно сразу открывать в плеере.

Список слов можно сохранить кнопкой **«Сохранить список»** в `.txt`-файл
и в следующий раз просто загрузить его обратно — не вводить заново.

## Для разработчиков

Исходный код — `subtitle_filter_app.py`, написан на Python (tkinter).

Запуск без сборки:

```
python subtitle_filter_app.py
```

Сборка своего `.exe`:

```
pip install pyinstaller
pyinstaller --onefile --windowed --name "SubtitleFilter" subtitle_filter_app.py
```

Готовый файл появится в `dist/SubtitleFilter.exe`.
