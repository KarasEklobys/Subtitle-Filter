# Фильтр субтитров по словам

Настольная программа для Windows: оставляет в `.srt` файлах только те строки,
где встречаются нужные тебе слова, а остальное убирает. Таймкоды не трогаются —
файл сразу открывается в PotPlayer (или любом другом плеере) вместо оригинала.

Полезно, когда обрабатываешь субтитры пачками (например, через Whisper) и
хочешь быстро найти только нужные моменты по ключевым словам, без ручного
пролистывания.

## Возможности

- Список слов — просто список, по одному слову/фразе на строку. Регистр
  букв не важен.
- Галочка «только целые слова» — чтобы слово «рот» не подхватывало «ворота».
  Если её выключить — ищется как часть любого слова.
- Список слов можно сохранить в `.txt` и в другой раз просто загрузить —
  не набирать заново. Новые слова просто дописываются в список.
- Можно выбрать сразу много `.srt` файлов или целую папку — обработает все
  разом (проверено на пачках по 100 файлов).
- Результат складывается в подпапку `filtered` рядом с исходными файлами,
  имена вида `видео.filtered.srt`.
- Внизу лог: по каждому файлу видно, сколько строк совпало из скольких.

## Как запустить без сборки (сразу, для проверки)

Нужен Python 3.10+ (у тебя стоит 3.14 — подходит).

```
python subtitle_filter_app.py
```

Откроется окно программы. `tkinter` идёт в комплекте со стандартной
установкой Python с python.org, ничего доустанавливать не нужно.

## Как собрать в .exe

Git Bash не нужен — всё через обычный терминал (PowerShell, cmd или
встроенный терминал VS Code).

1. Открой папку проекта в VS Code, открой терминал (`` Ctrl+` ``).

2. Установи PyInstaller (один раз):

   ```
   pip install pyinstaller
   ```

3. Собери exe:

   ```
   pyinstaller --onefile --windowed --name "SubtitleFilter" subtitle_filter_app.py
   ```

   Разбор флагов:
   - `--onefile` — всё упаковывается в один `.exe`, без кучи файлов рядом.
   - `--windowed` — без чёрного консольного окна при запуске.
   - `--name "SubtitleFilter"` — имя итогового файла.

4. Готовый файл появится тут:

   ```
   dist/SubtitleFilter.exe
   ```

   Это уже полностью самостоятельная программа — можно копировать на любой
   Windows-компьютер, Python на нём для запуска не нужен.

5. (Необязательно) Если хочешь свою иконку — добавь `.ico` файл в папку и
   собери с флагом `--icon "icon.ico"`.

### Если после сборки что-то не так

- Если exe при запуске сразу закрывается — на секунду убери `--windowed` и
  пересобери, тогда откроется консоль с текстом ошибки.
- Папки `build/` и файл `SubtitleFilter.spec`, которые появятся после сборки,
  можно смело удалять или не коммитить в git — это временные файлы сборки.
  Из репозитория обычно исключают `build/`, `dist/` и `*.spec` (положи их в
  `.gitignore`), а сам `.exe` при желании прикладывают отдельно к релизу на
  GitHub (Releases), а не в сам код репозитория — так репозиторий останется
  лёгким.
